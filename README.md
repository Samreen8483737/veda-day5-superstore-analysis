## Project Overview
This repository contains my submission for Day 5 of the Veda Data Analytics Internship. The task involved cleaning data, formatting date structures, and building multi-level PivotTables to answer high-level business questions.

## Tool Used
Microsoft Excel / Google Sheets

## Key Findings Summary
An analysis of the Superstore dataset reveals that **Technology** is our strongest revenue-driving category, generating over $836,000 in total sales. Geographically, the **West** region dominates overall performance compared to the Central, East, and South regions. Additionally, examining historical monthly sales trends shows that **November 2017** generated the highest monthly revenue ($89,306), indicating a significant historical peak in sales volume.
